# Study card guidance — learner visual checklist

Run on the built export, not the dev server.

- **The gate.** Open a typed card. **Answer** is dim and does nothing; Enter
  does nothing. Type one letter: it enables. Clear the field: it dims again.
  Type spaces only: it stays dim.
- **The ghost.** On a beginner deck, type the first few letters of the expected
  line. The rest appears as a quiet ghost after the cursor; the typed part looks
  normal. Type a letter that no expected answer starts with: no ghost.
- **Accepting.** Press Tab. The whole expected answer fills the field, the ghost
  disappears and **Answer** enables. Clear and repeat with the right arrow (the
  cursor must be at the end of the line) and with the **Complete** control.
  With sound on, each accept gives one short, soft tick, not the outcome chime.
- **I don't know.** Clear the field and press **I don't know**. The answer
  reveals and the card is recorded as missed. The **Answer** button never
  enabled on an empty field.
- **The levels.** Study the same card from an intermediate deck: no ghost, but
  the gate still works.
- **Other shapes.** A cloze card has no ghost; one filled blank enables
  **Answer**. A picks card has no aids and behaves as before.
- **The phone.** At 390px, the ghost, **Complete**, **Tab or →** and
  **I don't know** fit without a sideways scroll, and the action row still pins
  cleanly.
- **The look.** Check light and dark themes: the ghost is readable but clearly
  quieter than typed text, and it sits on the same line as the input.
