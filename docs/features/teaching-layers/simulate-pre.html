    When media fails

    • The card never depends on media. Text, question and answer stay usable.
    • Dead or blocked YouTube: the search text and an “Open on YouTube” link. No endless spinner.
    • Broken web image: a placeholder with the alt text and a link to open it.
    • Missing local file: “This file is not on this device” plus “Choose the file again”.
    • Built-in media must be in the offline cache, or it fails like a web image.
    • The app retries only when the learner reopens the layer or the card.

    Editing identity

    Teaching layer changed: the card is updated in place. Evidence stays; a pack update that only fixes an explanation does not retire the card.

    Question or answer changed: a new card is created. The old card is retired and keeps its evidence.
