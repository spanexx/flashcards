Answer speech - design simulation

The answer reveal gains one control. It speaks the answer in the pack's language, keeps numbers in that language, and never reads code symbols. Hardcoded cards; nothing is saved.

Answer · Polish pack
Prompt: Fill the blank in the Polish line.
My jedliśmy obiad. We were eating dinner.

What the learner hears

Both text parts, in display order: the Polish line, then the English translation.

Language tag: pl. The device voice for Polish reads it, so any number would follow Polish.

Answer · English pack
Prompt: Read the Polish line, then type the full English line.
There are 3 apples and 12 pears.

What the learner hears

"There are three apples and twelve pears."

Language tag: en. Numbers stay in the learning language.

Answer · Python pack
Prompt: What does this line print?
print(2 ** 3)
It prints 8: the double star means "to the power of".

What the learner hears

The text part, then the card's teaching text as the explanation.

Raw code is skipped. Teaching text: "The double star is exponentiation."

Answer · Python pack, no teaching layer
Prompt: What does this line print?
print(2 ** 3)
print(2 ** 3)

What the learner hears

"This answer is code. Read it on screen."

No teaching text, so one short line names the code instead of reading symbols.
